About this comparison

Starting with 2.0.0, benchmarks compare Orpheus directly against Dapper (a micro-ORM, closest in spirit to Orpheus's explicit CRUD model) and Entity Framework Core (the dominant full-scale .NET ORM), across Insert/Load/Update/Delete at 10, 100, and 1000 rows. Ratio/RatioSD are relative to Dapper's mean at that row count (Dapper = 1.00).
